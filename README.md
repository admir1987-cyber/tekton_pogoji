# Tekton: Terms of Use

Terms of use for Tekton, a construction site diary app for Android and iOS.

**Live:** [Pogoji uporabe / Terms of Use](https://admir1987-cyber.github.io/tekton_pogoji/)

The page is bilingual, Slovenian and English. It is linked from inside the app
and from the app store listings, where both stores require a public terms page.

## About Tekton

Tekton is a construction site diary you fill in by talking, not typing.
Quantities, photos and the daily report, done before you leave the site.

Built with Flutter and Dart by [Kaden Digital](https://www.kaden-digital.com), Ljubljana.
